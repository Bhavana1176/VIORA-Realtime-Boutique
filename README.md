# VIORA Realtime Boutique — React/Vite

## What is included
- Real SPA navigation with React Router
- Every main category opens its own collection page
- Collection pages show all related products
- Product details page
- Add to Cart with quantity controls
- Wishlist add/remove
- Cart persists in LocalStorage
- Wishlist persists in LocalStorage
- Search and collection filters
- Price/rating sorting
- Order Now button
- Checkout form
- Demo Cash on Delivery order flow
- Order confirmation screen
- Responsive mobile navigation
- VIORA branding and supplied contact details

## Start
npm install
npm run dev

## Important
This is a frontend ecommerce project. The order flow is a working demo stored in the browser. For real production orders, authentication, inventory, database and online payments, connect a backend such as Spring Boot + MySQL or Node.js + MySQL and a payment gateway.

## Product photos
The demo uses fashion image URLs so the UI has complete visual content. Replace the image fields in src/data/products.js with VIORA's own product photos when available.
